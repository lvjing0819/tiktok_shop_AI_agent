# 沙箱文件产物、权限与生命周期

## 首版范围

在现有Harness和离线执行器上增加固定`pricing_export_v1`任务。运营任务`product.prepare_listing`新增可选`export_pricing_report: true`；省略时保留原JSON定价流程。导出使用相同公式，计算后复核同一业务快照，工具版本升为3。首次部署需重新运行`scripts.setup_sandbox`构建v2镜像；旧v1镜像不会被新策略选中。

只支持服务端预登记的小型UTF-8 JSON定价文件。单文件最多8KiB、全部声明文件最多12KiB，通过现有32KiB有界stdout的base64包传输。没有任意文件上传/路径读取接口，也不适用于图片或视频；大型媒体未来需要独立流式传输和类型校验。没有使用Docker cp在停止后读取tmpfs，也没有向容器挂载宿主共享目录。

## 分类与校验

文件用途与敏感程度分开，不能互相代替。固定策略定义`pricing.json`为正式产出/restricted，`intermediate.json`为临时/restricted。任务声明必须与服务端策略完全一致，不允许Agent把敏感报告标成public。临时文件只传固定worker报告的元信息，正文留在容器tmpfs，随容器回收；其正文没有在宿主做二次扫描，也不会归档。

固定worker收集文件时使用目录描述符、O_NOFOLLOW/O_NONBLOCK和fstat，拒绝越界文件名、符号链接、硬链接、多链接文件、目录及超大文件。宿主不按声明路径打开本地文件，只验证固定文件名、数量、字节数、校验值、编码、实际JSON结构和分类。当前正式文件仅含proposed_price/proposed_channel_quantity，额外字段、活动内容标记、凭据字段、常见凭据模式和与当前配置匹配的已知密钥都会拒绝。

这是固定类型安全校验和有限凭据检测，不是通用杀毒或完备DLP，不能保证发现任何类型的恶意文件或未知秘密。新文件类型必须另行登记、实现校验，不能以现有检查放行任意内容。

## 加密暂存与正式交付

只有容器停止/回收确认、执行尝试仍有效后，才接收文件包。所有正式文件先加密暂存，快照复核、输出内容与业务结果一致性检查通过后，与上架草案在同一数据库事务中标为available并附加file_refs。版本变化或草案保存失败时，暂存记录标记discarded，回收其加密正文。崩溃留下的未发布文件按暂存期限和执行尝试有效性进入清理流程，不能提前下载。

使用Fernet认证加密。`SANDBOX_ARTIFACT_KEY`为空时复用已配置的`ADS_TOKEN_ENCRYPTION_KEY`，缺失或无效时拒绝文件持久化，不退回明文。密钥只在业务服务中使用，不传进容器。存储根目录默认`.sandbox-files`并已加入.gitignore，工作区目录使用哈希、文件名使用服务端UUID，目录0700/正文0600，不接受外部路径。

密文内绑定workspace、file_id和checksum，防止调换文件；读取前认证解密并校验长度和摘要。文件body加密不代表整个业务数据库、聊天或所有工具结果均已加密。Agent读取定价文件只得到批准的定价字段，这些字段继续按现有业务工具结果方式保存，不把任意文件原文写入工具日志。

备份必须同时包含数据库、文件存储目录和安全保管的加密密钥；单独备份SQLite不能恢复文件正文。不要删除或自动重生成仍有文件依赖的密钥。当前未提供密钥轮换管理界面。

## 权限与审计

保持单一所有者工作台访问模式；工作区过滤不是多用户/多租户登录认证。用户下载须通过原访问令牌和工作区校验，返回attachment、nosniff和no-store，不提供HTML内联预览。过期下载返回410，未知/跨工作区返回404，暂存文件不可下载。

`artifact.read_pricing`仅对product/content角色开放。读取必须绑定有效Harness执行；文件必须来自同一任务当前计划中已完成的直接依赖步骤，且来源attempt一致。没有跨任务自动共享，也不允许Agent读取任意宿主路径。跨任务授权、通用文档读取和任意执行代码不在首版范围。

`sandbox_file_event`记录run/step/attempt/sandbox、执行者类别、文件标识、分类、元信息、动作与时间，涵盖校验、临时文件丢弃、暂存、发布、读取、拒绝、保留设置、到期和正文回收。不写文件正文、密钥值或未验证的任意路径。当前为文件生命周期审计，不是所有open/write系统调用追踪；固定worker未声明的每个临时文件操作不会被自动逐次记录。单一所有者模式只记录owner类别，不冒称已有个人身份审计。

## 保留与回收

接入已有每日清理开关、预览、指纹复核及7天缓冲，不新增队列，不改变自动清理开关。普通已发布文件沿用结果默认30天；未发布暂存文件默认1天后可进入缓冲期，仍有效的执行尝试受到保护。显式长期保留、未结束/待核对任务和有效草稿的文件引用受到保护，保留设置或引用变化会使旧清理预览失效。

先提交expired墓碑并拒绝读取，再删除密文，避免数据库事务回滚时出现有效引用指向已删除正文。物理删除失败保留待回收状态，后续维护重试；只有body_removed_at存在才表示已确认删除。固定私有目录里没有数据库记录、超过7天的UUID密文孤儿可回收，其他文件不动。文件审计按已有概要期限（默认180天）并经过缓冲期回收，保留文件墓碑。

会话、摘要、长期偏好、订单、财务账本、实物库存及授权数据不属于本轮文件清理范围。

## 接口与任务中心

- `GET /api/agent-files/{uuid}`：元信息、revision及正文回收状态。
- `GET /api/agent-files/{uuid}/download`：鉴权后下载原始文件字节，记录读取事件。
- `PUT /api/agent-files/{uuid}/retention`：revision/pinned，版本冲突409。
- `GET /api/agent-files/{uuid}/events`：最近100条该文件审计。
- `GET /api/operations/{id}/file-events`：包括拒绝、临时文件丢弃在内的任务文件审计。

任务中心按file_refs显示下载、长期保留和审计按钮；blob下载沿用同一鉴权请求，不把令牌放进URL。原始正文无base64长期内联到任务数据。

## 验证

普通测试验证文件策略、加密、作用域/依赖授权、版本冲突、失败补偿、引用保护、过期和回收。真实文件创建/回收及隔离须在Docker已启动、v2镜像构建后运行：

```sh
.venv/bin/python -m scripts.setup_sandbox
RUN_DOCKER_SANDBOX_TESTS=1 .venv/bin/python -m pytest tests/test_sandbox.py -q
```

真实测试使用临时数据库、临时目录和随机测试密钥，不访问实际店铺数据。Docker不可用时不在宿主回退；跳过真实测试不代表隔离已通过验收。
